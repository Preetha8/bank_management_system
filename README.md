# Bank Account Management System

A Python OOP project demonstrating a simple bank account management system.

## OOP Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Method Overriding
- Polymorphism
- Constructors
- super()

## Features

- Deposit money
- Withdraw money
- Check balance
- Display account details
- Savings account with insufficient balance validation
- Current account with overdraft facility

## Technologies

- Python
- Object-Oriented Programming
